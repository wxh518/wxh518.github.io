# 主页模块对照记录

参照页面：[qzq.at](https://www.qzq.at/)。对照日期：2026-10-17。桌面视口 1440×1000，手机视口 390×844；桌面内容宽度为 1178px（包含浏览器 6px 滚动条的影响）。

| 模块 | 本次修正与验证 |

| 社交 | 使用六种原站深色背景，增加配置驱动的多项统计，校准卡片边框、字号和双向滚动轨道。 |
| 工作与技能 | 项目标题改用 Coda；技能改为上方两行四列、下方两张卡夹住 Skills 标牌；文本从顶部 32px 对齐，进度使用原站的块字符。悬停说明、关联连线和弹窗保留。 |
| 游戏 | 替换演示封面，校准左侧 16:9、右侧正方形封面及 24px / 36px 标题。 |

| 音乐 | 使用原站乐队、动态图和透明乐器素材，恢复 256 / 304 / 256px 三行拼贴、自然比例的顶部裁切、两层视差和两行 Code + Music 标牌；整体高度 848px。 |
| Time | 以真实年龄间距绘制平滑堆叠面积图，移除旧图例、网格和年龄按钮，恢复图内标签、百分比坐标及 Age 文案。5 条面积路径的 SVG 字符串逐条与参照页相同。 |

## 配置与验证

数据、素材地址、配色、图内标签和地图定位均在 `content/homepage.json`。中文字段说明及校验约束在配套 JSON Schema 中；素材原始公开地址记录在 `public/images/reference/sources.json`。静态图片按网页尺寸生成 WebP，透明度保留，GIF 保留原格式；参考素材由约 16.3MB 降至 2.9MB，原图保留在本机备份，映射见 `web-assets.json`。这些图片与数值用于演示对照，不代表主页所有者的真实作品、身份或经历。

验证：23 项测试、前后端 TypeScript 检查、配置校验、前端生产构建和 Worker 打包通过。浏览器验收覆盖图表键盘提示、作品弹窗、手机菜单、书架分类、博客入口和图片加载；390px 视口没有页面横向溢出。
