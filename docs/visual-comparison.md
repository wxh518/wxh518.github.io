## 配置与验证

数据、素材地址、配色、图内标签和地图定位均在 `content/homepage.json`。中文字段说明及校验约束在配套 JSON Schema 中；素材原始公开地址记录在 `public/images/reference/sources.json`。静态图片按网页尺寸生成 WebP，透明度保留，GIF 保留原格式；参考素材由约 16.3MB 降至 2.9MB，原图保留在本机备份，映射见 `web-assets.json`。这些图片与数值用于演示对照，不代表主页所有者的真实作品、身份或经历。

验证：23 项测试、前后端 TypeScript 检查、配置校验、前端生产构建和 Worker 打包通过。浏览器验收覆盖图表键盘提示、作品弹窗、手机菜单、书架分类、博客入口和图片加载；390px 视口没有页面横向溢出。
